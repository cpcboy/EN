# 03 · 开发路线图（单人 + AI）

> 假设：兼职开发（每周 ~20 小时），全职可把日历时间压缩约 40%。
> 每个里程碑都带**继续 / 调整 / 止损**判据——单人开发最常见的死法是"没人要的东西做了两年"，判据就是防这个的。

---

## 1. 引擎与工具链选型

### 引擎：Unity 6（推荐结论）

| 维度 | Unity 6 | Unreal 5.x | Godot |
|---|---|---|---|
| 单人上手与迭代速度 | ✅ C#、生态教程最全 | 学习曲线陡、编译重 | ✅ 轻 |
| iOS + PC 双端 | ✅ 最成熟（URP 一套管线两端跑） | 可行但移动端调优负担重、包体大 | 一般 |
| 写实角色管线 | ✅（见下） | ✅ MetaHuman 原生最强 | ❌ 弱 |
| 资产商店 | ✅ 最丰富 | 好 | 少 |
| AI 编码助手友好度 | ✅ C# 语料最多 | C++/蓝图较弱 | 一般 |
| 费用 | 个人免费（收入 <$20 万；Runtime Fee 已于 2024.9 取消） | 免费（<$100 万后抽 5%） | 免费 |

**结论**：Unity 6 + URP（一套管线，PC 开高、iOS 降档）。Unreal 的写实优势对本作不构成翻盘理由——docs/00 已论证半写实/风格化画风更稳，而 Unity 做半写实绰绰有余。

### 角色制作管线（二选一，M1 前定）
- **方案 A：MetaHuman → Unity**（2025.6 起官方允许在 Unity 使用且不触发 5% 分成）：免费、质感强；需做 LOD/材质简化才能上 iOS。适合偏写实端。
- **方案 B：Character Creator 5**（$299 买断）：导出即带游戏级拓扑与 ARKit 52 表情，iOS 友好，风格可调——**默认推荐**，省下的调优时间值回票价。
- 场景与道具：Unity Asset Store 风格化资产打底（预算 $100–300）+ AI 辅助概念图定调（注意 Steam 披露，见 docs/04 §5）。

### 单人 + AI 工作流
- **代码**：Claude Code 写 C# 玩法逻辑、Workers 代理、SQL/检索管线（效率工具，Steam 2026.1 新规明确无需披露）。
- **美术**：买资产为主 + AI 概念图定风格 + 人工修整；**玩家可见的 AI 生成素材要在披露表如实填写**。
- **音频**：TTS 即配音（本作天然如此）；BGM 用授权曲库（Epidemic Sound 等，~$15/月）或委托 1–2 首主题曲。
- **文案**：人设卡与关键剧情人写（角色灵魂不外包给 AI），日常对话由 LLM 运行时生成。
- 每周 20h 参考分配：10h 开发 / 4h 美术资产整合 / 3h 内容与营销（devlog、短视频）/ 3h 测试复盘。

## 2. 里程碑

### M0 · 技术验证原型（第 1–2 月）——先证死生，再谈美术
- 灰盒场景 + 占位角色：跑通 **LLM（含缓存）→ 流式分句 TTS → uLipSync 口型** 全链路
- Workers 代理 + Supabase + pgvector 记忆雏形（L0 画像 + 情景检索）
- **第 0 号验证**（docs/02 §9 清单）：模型档位盲测、首音延迟 <2s、1000 轮成本压测
- 行政并行：**立即注册 Steam 开发者账号并付 $100**（30 天等待期提前消化，docs/04）；注册游戏社媒账号开始 devlog
- ⛔ **止损判据**：实测单用户成本 > docs/02 §7 估算的 2 倍且无降档空间，或延迟无法 <4s → 不进 M1，先重做技术方案（更小模型/文字优先/预生成混合）

### M1 · 垂直切片（第 3–4 月）
- 正式角色资产（CC5 制作小满）+ 灯塔咖啡馆场景 + 昼夜光照
- 好感 1–3 阶段、记忆 v1 完整（含记忆册 UI）、共同活动"堤岸散步"
- 安全护栏 v1 全链路（含危机协议）；中英双语框架
- ✅ 验收：给 5–10 个陌生人玩 30 分钟，至少一半人出现"她居然记得"时刻并愿意第二天回来
- ⛔ 止损判据：试玩者普遍反馈"就是个套壳聊天"→ 回炉情绪价值机制（docs/01 §5），暂停场景扩张

### M2 · 曝光启动（第 5 月）
- **Steam Coming Soon 页上线**（愿望单开始积累；素材：30 秒"她记得我"概念预告 + 截图）
- Steam Playtest 20–50 人封测（渠道：devlog 粉丝、Reddit r/CozyGamers、AI 陪伴社区）
- 每周迭代：对话质量、延迟、额度话术
- ⛔ 调整判据（数据基准见 docs/00 §3）：页面上线 8 周愿望单 <1,000 且宣传素材已迭代 3 版 → 重做钩子（标题/首图/预告结构甚至画风），**先修曝光再写代码**

### M3 · Demo → Early Access（第 6–8 月）
- 免费 Demo（独立 appID，含每日额度的完整体验切片）；报名最近一届 **Next Fest**（2/6/10 月，每游戏一生一次，按中位数 +200 愿望单做预期）
- 海滩场景 + "看日落" + 好感 4–5 阶段 + 黄昏信上线
- **EA 发售**：定价 $9.99–12.99（docs/07），发售折扣注意 30 天折扣锁规则（docs/04 §7）
- ✅ 目标参考：发售时愿望单 ≥5,000（转化 ~15% → 首周 ~750 份）
- ⛔ 止损判据：EA 首月 <500 份且好评率 <75% → 停止内容扩张，读差评分流：体验问题 → 修核心；需求问题 → 启动 B 计划（转 iOS 订阅 App 形态优先，数据显示钱在 App，docs/00 §4）

### M4 · iOS 版（第 9–12 月）
- **注册 Apple 开发者**（$99/年从此刻起算，别提前烧年费；1–2 天过审，docs/05）
- URP 降档适配（目标 iPhone 12 起 30fps）、触屏交互、IAP 订阅接入（申请 Small Business Program 15%）
- App Store Connect：**可用地区排除中国大陆**；隐私标签、账号删除、第三方 AI 点名同意弹窗（docs/05 红线清单逐项过）
- TestFlight 内测 → 外测 → 提审（预留 2–3 轮被拒重提的时间缓冲）
- ✅ 全平台在售 + 第 2 位角色开工（转入二期蓝图）

### 贯穿全程
- 每月月底：成本报表（API 账单/DAU）对照额度模型修参数
- 政策雷达：Steam AI 政策、苹果审核指南、州法动态（docs/06 风险预案的触发器）

## 4. 风险登记册（Top 5）

| 风险 | 概率 | 缓解 |
|---|---|---|
| API 成本失控 | 高 | M0 压测 + 每日额度 + 熔断（docs/02 §7） |
| 曝光不足（愿望单停滞） | 高 | M2 判据强制"先修钩子再开发"；devlog 从第 1 天积累 |
| 平台政策突变（AI 陪伴类收紧） | 中 | 16+ 健康定位留足余量；多模型供应商抽象；B 计划分发（docs/06） |
| 单人范围失控 | 中 | v1 范围冻结（docs/01 §7"明确没有"清单）；新想法一律进二期清单 |
| LLM 扮演质量不稳（OOC/翻车） | 中 | 人设卡回归测试集（50 条固定问题月度回归）；输出扫描兜底 |
