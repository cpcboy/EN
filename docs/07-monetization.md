# 07 · 商业化与成本测算

> 核心命题：**AI 陪伴的边际成本不为零**（每分钟对话都在烧 API），所以商业模式必须让"用得多的人付得多"，同时不背叛"好感不出售"的红线。
> 数据依据见 docs/00 §4；成本模型见 docs/02 §7。

## 2. 双平台商业模式

### Steam（EA 买断 + 内置额度 + 可选订阅）
- **买断 $9.99–12.99**：永久包含"基础额度"——每日 60 轮文字 + 10 分钟语音（覆盖 90% 玩家的正常使用；额度以"她今天的空闲时间"世界观话术呈现）
- **可选订阅 Companion+ $9.99/月**：高额度语音、黄昏信全语音、（远期）实时语音通话
- **预期管理（Steam 玩家抵触"买断内订阅"，官方文档都承认订阅接受度有限）**：
  1. 商店页明示"买断含每日额度，订阅只加量、不锁功能、不锁好感"
  2. 红线可视化：**关系进展与剧情永不付费墙**（差评防火墙 + 伦理红线同一条）
  3. 给高级玩家留 BYO-key 通道（自带 API key 解除额度，AI2U 已验证此模式）——技术用户的好评杠杆
- EA 定价即长期定价（30 天折扣锁 + EA 涨价反感，见 docs/04 §7）

### iOS（免费下载 + 订阅，走 IAP）
- **免费层**：每日 15 轮文字 + 语音试用；记忆功能完整保留（记忆是信任资产，免费层也不裁——转化钩子是"更多相处时间"，不是"她记不记得你"）
- **订阅同档 $9.99/月**（与 Steam 订阅同权益，苹果 IAP 计价）
- Small Business Program 后苹果抽 15% → 到手 ~$8.49/订户/月

## 3. 单位经济测算

**成本侧**（docs/02 §7）：重度用户 ~$2.5–3.5/月；典型订阅用户 ~$1.5–2.5/月；免费层用户（15 轮文字）~$0.2–0.4/月。

**毛利**：

| 渠道 | 收入/用户/月 | 平台抽成 | API 成本 | 毛利 |
|---|---|---|---|---|
| iOS 订阅 | $9.99 | -15%（SBP） | ~$2.0 | **~$6.5（65%）** |
| Steam 订阅 | $9.99 | -30% | ~$2.0 | ~$5.0 |
| Steam 买断（摊 12 个月） | $11.99 → ~$1.0/月 | -30% | ~$0.8（额度内轻中度） | ~微利——**买断是获客与品牌，订阅才是利润** |

**免费层可持续性**：每 25 个免费 iOS 用户的 API 成本 ≈ 1 个订阅用户的毛利 → 免费→订阅转化率只需 ~4% 即打平（陪伴品类付费转化通常高于此；Tolan 200K MAU / 100K 付费是极端正面样本）。

## 5. 成本工程优先级（利润的另一半）

1. Prompt 缓存命中率 >85%（人设段稳定不动）
2. 闲聊轮次路由便宜模型（DeepSeek 档），情感重轮次才用主力模型 → 混合后 LLM 成本再降 ~40–60%
3. 输出长度约束（聊天式短回复，更真实也更便宜）
4. TTS 分层：日常 MiniMax，关键剧情 ElevenLabs
5. 黄昏信等异步内容走 Batch API（-50%）
6. 代理层熔断：单用户日成本帽 + 全局日预算告警（docs/02 §7）

**明确不做的变现**（负面清单）：出售好感度/关系进展、抽卡/开箱、断签惩罚式会员、情感勒索式推送付费——每一条都同时是伦理红线（docs/06 §4）和差评引信。
