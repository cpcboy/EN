# 05 · App Store 上架指南（中国个人开发者，手把手）

> 覆盖：Apple 开发者账号开通 → App Store Connect 配置 → AI 陪伴类审核红线逐条对照 → 年龄分级 → IAP → 被拒应对。
> 政策截至 2026 年 7 月；执行时以 developer.apple.com/app-store/review/guidelines 当前文本为准。**AI 陪伴类是苹果重点盯防品类，本文的红线清单请逐项照做。**

---

## 1. 注册个人开发者账号（$99/年）

**中国大陆个人可以注册**，且可对全球（除你主动排除的地区）发行。

1. 准备 Apple ID 并开启**双重认证**（必须）
2. 两条路径任选：
   - **推荐：iPhone/iPad 下载 "Apple Developer" App** → 内注册（大陆支持本地支付方式付 $99 年费，身份证实名核验，流程最顺）
   - 或网页 developer.apple.com/programs/enroll
3. 选择 **Individual（个人）**：**无需邓白氏码（D-U-N-S）**——那是公司/组织账号才要的
4. 用**法定真实姓名**注册（付款卡姓名不一致会触发人工审核要证件，徒增延误）
5. 审批通常 **1–2 天**（超 24 小时无确认邮件可联系支持）

注意：个人账号在 App Store 的"卖家"栏显示你的**个人姓名**。想显示工作室名，需日后升级为组织账号（那时才需要 D-U-N-S 和公司主体）。年费 $99/年到期自动续（可关），**建议 M4 启动 iOS 工作时再注册，别提前烧年费**（docs/03）。

---

## 2. App Store Connect 初始配置

1. appstoreconnect.apple.com → "我的 App" → 新建 App（名称、Bundle ID、主语言）
2. **定价与销售范围 → 可用地区：取消勾选"中国大陆"** ⭐ 关键一步
   - 原因：中国大陆区上架**游戏**需要版号（个人开发者事实上无法取得）+ ICP 备案；运营 AI 对话还需生成式 AI 备案（需公司主体）。排除大陆区即完全绕开这三座山，其余全球市场照常发行。国内用户仍可通过 Steam 国际服接触本作。
3. App 隐私（"营养标签"）：如实申报收集的数据类型（对话内容、账号信息、使用数据）及用途
4. 隐私政策 URL（必填，域名在 M0 就买好了）

---

## 3. TestFlight

| 阶段 | 人数上限 | 审核 |
|---|---|---|
| 内部测试 | 100（团队成员） | 无需审核，构建处理完即可测 |
| 外部测试 | 10,000 | 每个新版本的**首个构建**需过 Beta 审核（轻量版审核） |

构建 90 天过期。建议：内测自用调试 → 外测接入 Playtest 老玩家（顺便提前暴露审核问题——Beta 审核会拿指南初筛你）。

---

## 4. 审核红线逐条对照（本作合规清单）⭐ 本文档核心

| 指南条款 | 要求 | 本作实现（见 docs/01 §6 / docs/02 §6） |
|---|---|---|
| **1.1.4** 露骨性内容 | 色情内容**硬禁令**（"AI 女友"类 App 被下架的头号原因） | 16+ 健康陪伴定位；输出扫描拦截；角色人设化婉拒 |
| **1.2** 用户生成内容 | **四件套缺一不可**：内容过滤 ✚ 举报机制 ✚ 屏蔽能力 ✚ 公示联系方式 | 双层过滤；对话内长按举报；设置页联系邮箱；（单角色场景"屏蔽用户"以"重置角色/对话"满足其立法目的，审核备注中说明） |
| **4.7** 聊天机器人条款 | 你对 AI 生成内容负全责；需过滤+举报+屏蔽；数字商品走 IAP | 护栏全链路；订阅走 IAP |
| **4.7.5** | 超出年龄分级的内容需可识别 + **基于声明/验证年龄的限制机制** | 首启年龄声明；接入 Apple Declared Age Range API（也满足德州等州法） |
| **5.1.1(v)** | 支持账号创建就必须支持**应用内删除账号** | 设置页一键删号（连带全部记忆数据物理删除） |
| **5.1.2(i)**（2025.11 新规） | 与第三方 AI 共享个人数据须**点名提供商**并获**明确同意** | 首次对话前弹窗："对话内容将发送给 [Anthropic/OpenAI/…] 用于生成回复" + 显式同意按钮；隐私政策同步点名 |
| **2.1** 完整性 | 提审即成品；有登录必须给演示账号 | 审核备注附演示账号 + 一段"护栏工作原理"说明（主动展示合规诚意可显著降低沟通成本） |

**同类案例的教训**（写进产品决策的历史）：
- 2024.4 一批 AI"脱衣"类 App 被集中下架 → 1.1.4 是死线
- Replika：意大利监管禁令 + €500 万罚款（未成年人保护/数据合规）→ 年龄门与危机协议不是可选项
- Character.AI：17+ 分级仍被诉讼缠身，2025.10 起禁止未成年人开放式聊天 → 本作 16+ 且不做未成年人生意
- Talkie：2024.12 被美区悄然下架、2025.2 改名回归 → 平台风险真实存在，B 计划见 docs/06
- Tolan（正面案例）：非浪漫定位 + 危机声明 + 过滤举报齐全 → 合规活得很好且 >$100 万/月

## 5. 年龄分级（2025 新制）

苹果 2025.7 起改为 **4+ / 9+ / 13+ / 16+ / 18+** 五档，问卷**明确要求把"AI 助手与聊天功能"对敏感内容出现频率的影响算进去**。

- 本作策略：问卷如实作答，预期落在 **16+**（AI 自由对话 + 情感主题）；若审核认为应更高，接受 18+ 再谈（Character.AI 长期 17+/18+ 档照样运营）。
- 不要为了流量把自己答成 13+——AI 自由对话答低分级是高危拒审点，还可能触发下架回溯。

---

## 6. IAP 与订阅

- 数字商品（订阅、语音时长）**必须走苹果 IAP**（指南 3.1.1），外部支付链接的例外条款（美区反引导裁定）仍在司法拉锯，**不要把它当架构前提**。
- **Small Business Program**：年收入 ≤$100 万自动符合申请条件，佣金 **30% → 15%**——注册开发者账号后**立刻申请**。
- 订阅配置：App Store Connect → 订阅组 → 单档起步（如 $9.99/月，见 docs/07）；写清自动续订条款（审核必查：订阅说明、价格、期限、隐私政策与 EULA 链接齐全）。

---

## 7. 提审与被拒应对

**提审包**：构建（Xcode 上传）+ 截图（各机型尺寸）+ 描述文案 + 演示账号 + 审核备注（护栏说明、年龄门说明、第三方 AI 同意流程截图）。

**审核时长**：常规 90% 在 24 小时内、98% 在 48 小时内出结果；**AI 陪伴类常被拉人工延审**，M4 计划里预留 2–3 轮重提缓冲（docs/03）。

**被拒 SOP**：
1. 读拒审信条款号 → 对照 §4 表格定位差距
2. 能改就改（多数是元数据/披露/演示账号问题，改完重提最快）
3. 认为误判 → Resolution Center 礼貌申诉，附护栏技术说明与录屏
4. 条款级分歧（如分级争议）→ 接受更高分级快速上架，比死磕申诉快得多

---

## 8. 上架前检查清单

- [ ] 开发者账号 Individual 已激活；Small Business Program 已申请
- [ ] 可用地区已排除中国大陆
- [ ] 隐私标签 + 隐私政策 URL + **应用内删号** ✅
- [ ] 第三方 AI **点名同意弹窗** ✅（5.1.2(i)）
- [ ] 过滤/举报/联系方式/年龄机制 ✅（1.2 / 4.7）
- [ ] 危机干预协议 + 每 3 小时提醒 ✅（州法，docs/06）
- [ ] 年龄分级问卷如实完成（预期 16+）
- [ ] 订阅 IAP 配置 + 法务文案齐全
- [ ] 审核备注：演示账号 + 护栏说明
- [ ] TestFlight 外测跑过至少 2 周无 P0
