# 01 · 游戏概念与灵感

> 本文档定义游戏是什么：世界观、角色、玩法循环、情绪价值机制与 v1 范围。
> 设计原则来自 docs/00 的数据结论：**窄而深、健康向、成本可控、不打"AI"旗号打"陪伴"旗号**。

---

## 1. 定位与差异化

**一句话**：一座可以漫游的温暖 3D 小岛，那里住着一位真正记得你的人。

**电梯陈述**：玩家搬到一座慢节奏的海岛，认识了灯塔咖啡馆的老板娘"小满"。她由 AI 驱动——能听懂你的情绪、记得你说过的每一件事、在你需要的时候恰好在场。这不是一个"攻略角色"的游戏，而是一段"被人记得"的体验。

### 竞品矩阵与空位

| 产品 | 3D 世界 | AI 实时对话 | 长期记忆 | 情绪健康导向 | 形态 |
|---|---|---|---|---|---|
| Grok Ani (xAI) | 立绘级 3D，无世界 | ✅ 强 | 部分 | ❌（NSFW 导向，$30/月） | App 附属功能 |
| Replika / Character.AI | 无 / 2D | ✅ | ✅ | 参差（有争议史） | 订阅 App |
| Talkie / 星野 | 卡片 2D | ✅ | 部分 | 参差 | 免费+内购 App |
| 恋与深空 | ✅ 极强 | ❌（剧本预写） | ❌ | 剧本可控 | 手游抽卡（大团队） |
| AI2U / Whispers from the Star | 房间级 3D | ✅ | 弱 | 惊悚/生存题材 | 买断游戏 |
| **本作** | **✅ 可漫游小世界** | **✅** | **✅ 全量+可管理** | **✅ 核心卖点** | **Steam 买断 + iOS 订阅** |

**空位**：市面上要么"有 AI 没世界"（陪聊 App），要么"有世界没 AI"（恋与深空），要么"有 AI 有 3D 但题材猎奇"（AI2U）。**"温暖的可漫游世界 × 真记忆 AI × 健康情绪价值"三者交集是空的。**

### 三条设计红线（贯穿所有文档）
1. **好感不出售**：关系进展只来自对话与陪伴的质量，不能用钱买（伦理红线 + 差异化卖点）。
2. **不惩罚离开**：几天不上线，她不会生气、不搞负罪感推送——只会温暖地说"欢迎回来"（反 dark pattern，直接回应 Character.AI 式"依赖设计"批评）。
3. **她希望你在现实里也好起来**：角色价值观内置"鼓励现实生活"，会记得你的现实目标并温柔跟进（合规 + 伦理 + 独特人设三合一）。

## 2. 世界观：心屿

**工作名候选**（发售前做商标与 Steam 重名检查）：
1. **《心屿》Heartside** —— 主推。"心之屿"，中英都好记，域名/社媒可注册性好。
2. 《小满未满》Nearly Full —— 取自角色名与节气哲学："将满未满，才是恰到好处"。适合作副标题。
3. 《暮色港湾》Dusk Harbor —— 氛围向备选。

**设定**：一座亚热带小岛的边缘，有一座由旧灯塔改造的咖啡馆。玩家因为"想离开一阵子"（开场留白，由玩家自己填写原因——这个回答会被小满记住，成为第一条记忆）搬到岛上。岛上时间真实流动：清晨有雾、正午海光、黄昏落日、夜里灯塔扫过海面。天气与时段改变场景光照、小满的位置与话题。

**v1 场景范围**（A Short Hike 式尺度，步行 3–5 分钟走完，但值得反复来）：
- **灯塔咖啡馆**（室内）：吧台、窗边座、二楼露台。小满的主场。
- **堤岸步道**（室外）：长椅、邮筒、猫出没点。散步对话的舞台。
- **小海滩**（室外）：篝火位、观日落点。解锁"看日落"活动的地方。

**二期蓝图（v1 验证成功后展开，见 docs/03 止损判据）**：小镇主街、书店、天文台；第 2–4 位角色各有作息表与生活轨迹，玩家在不同时间地点自然邂逅——即最初"逛世界结交不同情感伴侣"的完整愿景。**架构上从 v1 起就为多角色预留**（角色人设卡、记忆库、语音配置均按"每角色一套"设计，见 docs/02）。

## 3. 首发角色：小满（Xiaoman）

| 项 | 设定 |
|---|---|
| 名字 | 小满（取自节气；"小满未满，是最好的状态"是她的口头哲学） |
| 年龄感 | 25–28 岁 |
| 身份 | 灯塔咖啡馆老板娘；前城市白领，三年前搬到岛上 |
| 性格原型 | 温柔倾听者 × 恰到好处的幽默 × 有自己的生活（不是"永远待机的客服"） |
| 说话风格 | 短句、口语化、爱用比喻；情绪低的话题她会先共情再说话；偶尔反问，把话题还给你 |
| 她自己的故事 | 为什么离开城市？灯塔顶层锁着的房间是什么？——随好感度分阶段揭开（给关系推进以叙事奖励） |
| 边界（护栏人格化） | 面对越界请求，她有符合人设的婉拒方式；面对玩家的痛苦，她共情但会在危机时刻认真递上求助信息（见 §6） |
| 画风 | **半写实/风格化**（吉卜力×轻写实的质感方向），不追极致拟真——规避恐怖谷、AI 差评放大与审核风险（依据 docs/00 §4.4） |
| 声音 | 温暖的中低音女声，语速偏慢；中英双语各选一套 TTS 音色（docs/02 §4） |

**为什么先做"温柔倾听者"原型**：目标用户（孤独感强的单身人群）的第一需求是"被听见、被记得"，该原型对 LLM 的扮演稳定性要求也最低（相比傲娇/毒舌型不易翻车）。后续角色再覆盖其他情感原型（元气、慢热、知性）。

## 4. 核心循环与玩法系统

### 核心循环（一次 15–30 分钟的会话）
**漫游**（走走小岛，看看海）→ **相处**（找到小满：对话 / 共同活动）→ **被记得**（她引用你上次说的事，记忆册新增条目）→ **关系生长**（好感阶段推进，解锁新话题/活动/她的故事）→ **留下期待**（黄昏信、明日的约定）→ 下次再来。

### 对话系统（游戏的心脏）
- 文字输入 + 语音输入（Whisper STT）双模式；她以语音+口型+表情+动作回应。
- 对话不是菜单选项，是自由输入——**这是与恋与深空们的本质区别**。
- 情境感知：她知道现在是黄昏还是深夜、你们在吧台还是海边、你上次聊到哪——同一句"今天好累"，在不同情境会得到不同回应。
- 延迟目标：首字/首音 < 2 秒（流式输出 + 边生成边播报，docs/02 §7）。

### 共同活动（把"聊天"升维成"陪伴"）
v1 两个：**堤岸散步**（边走边聊，话题由场景触发）、**看日落**（坐在海滩，安静分享式对话 + 拍立得合影存入回忆相册）。
二期：咖啡拉花小游戏、篝火夜谈、一起听歌、桌游。
设计原则：活动是"对话的容器"，玩法轻量（单人做得起），情绪浓度高。

### 好感度系统：五个阶段（健康向，对标 Ani 的 5 级但反其道）
| 阶段 | 名字 | 解锁 |
|---|---|---|
| 1 | 初识 | 基础对话、咖啡馆话题 |
| 2 | 熟络 | 堤岸散步、她开始主动提问 |
| 3 | 知心 | 看日落、她的故事·上、纪念日系统 |
| 4 | 依恋 | 昵称、黄昏信、她的故事·下 |
| 5 | 心屿 | 灯塔顶层、专属承诺剧情（无露骨内容） |

- **推进逻辑**：由"对话深度 × 相处频率 × 关键剧情节点"驱动，**不设每条消息打分**（Ani 的 -10/+15 分制会诱导讨好式对话），不设礼物氪金加成。
- **不设降级惩罚**：长期不上线不掉阶段（红线 2）。

### 记忆玩法化（技术特性 → 情感体验，实现见 docs/02 §3）
- **记忆册**：她记住的关于你的事，以她的手账形式呈现——可翻阅、可修正（"这条记错了"）、可要求忘记（隐私合规 + 信任感玩法）。
- **纪念日**：第一次见面、第一次看日落……她会记得并提起。
- **回忆相册**：共同活动的拍立得，附她手写风格的一句话注记。
- **黄昏信**：每天黄昏她写一小段信（异步生成，成本低、情绪价值高、次日回访钩子）。

## 5. 情绪价值机制（"懂我"的具体实现）

1. **主动关心（事件跟进）**：你提过"明天有面试"，第二天她会先问"面试怎么样？"——由记忆系统的"待跟进事件"队列驱动（docs/02 §3）。这是所有调研中用户最高频的"被打动瞬间"。
2. **情绪感知模式切换**：识别到低落/焦虑 → 切换"倾听模式"（先共情、不给建议、不转移话题，直到你说完）；识别到分享欲 → 积极回应模式。
3. **仪式感**：纪念日、黄昏信、天气问候（岛上下雨时她多聊两句）。
4. **现实关照（红线 3 的落地）**：她记得你的现实目标（健身/学英语/找工作），温柔跟进但从不说教；深夜 2 点她会陪你，但也会说"我在这儿，不过你明天还要上班，要不要先睡？"
5. **她有自己的生活**：她会分享今天咖啡馆的小事、她在读的书——**单向倾诉是客服，双向分享才是关系**。

## 6. 安全与伦理内建（设计特性，非补丁）

| 机制 | 设计 | 对应合规 |
|---|---|---|
| AI 身份透明 | 开场以世界观化方式披露（她自我介绍时不装人类）+ 设置页常驻声明 + 每 3 小时会话温柔提示休息（融入角色口吻："去喝口水吧，我在这儿"） | CA SB 243 / NY 州法 / 平台要求 |
| 年龄门 | 16+；启动时声明年龄，接入 Apple 年龄信号 API | 苹果 4.7.5 / 德州法 |
| 危机协议 | 自杀/自残信号 → 她先真诚共情，然后自然地递上求助资源（各地区热线），不评判、不说教；高危会话不进入常规记忆 | CA SB 243 / NY / 平台 |
| 内容边界 | 恋爱、暧昧、情感倾诉都可以；无露骨性内容（她有符合人设的婉拒方式） | 苹果 1.1.4 / Steam AI 政策（实时 AI 成人内容绝对禁止） |
| 记忆主权 | 记忆册可查看/修正/删除；应用内一键删除账号与全部数据 | GDPR / 苹果 5.1.1(v) |
| 反依赖设计 | 红线 1/2/3；无每日签到惩罚、无"她在等你"式负罪感推送 | 伦理（C.AI 诉讼教训） |

## 7. MVP 范围（Steam Demo 版本 = M2/M3 交付物）

**必须有**：小满 1 角色（文字+语音对话、口型表情、好感 1–3 阶段）；灯塔咖啡馆+堤岸+海滩可漫游（昼夜循环）；记忆系统 v1（核心画像+情景记忆+记忆册）；共同活动 ×2；安全护栏全量（**不可裁剪**）；中英双语；每日对话额度机制（Demo 天然限额）。
**明确没有**：多角色、小镇、iOS 版、实时语音通话、活动小游戏、成就/收集系统。
**验收标准**：一个从未见过本游戏的玩家，20 分钟内经历一次"她居然记得"的瞬间，并在第二天想回来看黄昏信。

## 8. 灵感来源速记（做设计决策时回头看）

- **Needy Streamer Overload**：单角色深度 + 华语市场爆发力（51% 中国销量）→ 单角色不是妥协，是被验证的形态。
- **A Short Hike**：小而完整的 3D 漫游世界，单人可完成 → 场景尺度的标尺。
- **Grok Ani**：好感等级带来的进展感抓人 → 保留进展感，去掉打分制与 NSFW 依赖。
- **Tolan**：人格卡+向量记忆逐轮重建、非浪漫定位反而做到 $100 万/月 → 记忆架构参照 + "健康陪伴"商业上成立的证明。
- **Whispers from the Star**：情绪驱动的 AI 角色能撑起整个产品，但成本失控会毁掉口碑 → 成本工程前置。
- **恋与深空**：3D 亲密感（视线、距离、触碰反馈）的表现力标杆 → 学它的镜头语言与角色表现，不学它的内容跑步机。
