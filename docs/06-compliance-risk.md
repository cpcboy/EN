# 06 · 合规与风险

> AI 陪伴产品在 2025–2026 年从"灰色地带"变成了"被立法点名的品类"。本文档把法律义务翻译成产品功能，把平台风险翻译成预案。
> ⚠️ 本文档不构成法律/税务意见；上线前建议花小钱做一次正式法律审阅（尤其面向美国市场时）。

---

## 1. 法定义务 → 产品功能对照表

**美国州法已直接监管"陪伴聊天机器人"**（本作发行地含美国即适用）：

| 义务 | 法律来源 | 生效 | 本作实现 |
|---|---|---|---|
| 清晰披露"你在和 AI 对话" | 加州 SB 243；纽约州 AI Companion 法 | 2026.1.1；2025.11.5 | 首次会话披露 + 设置页常驻声明（docs/01 §6） |
| 会话开始及**每 3 小时**重复提醒 | 纽约州法（全员）；SB 243（对未成年人） | 同上 | 客户端计时器触发，角色口吻呈现（"聊了挺久啦，去伸个懒腰？我在这儿"） |
| 自杀/自残**危机协议**：检测 + 转介危机热线 | SB 243 + 纽约州法 | 同上 | 输入分类器 → 危机分支：共情模板 + 按用户地区显示热线（美国 988 等）；危机日志（docs/02 §6） |
| 对已知未成年人：禁止性内容 + 休息提醒 + "可能不适合未成年人"披露 | SB 243 | 2026.1.1 | 本作 16+ 且全域无露骨内容；年龄门 + Apple 年龄信号 API |
| 应用商店年龄核验配合 | 德州 App Store Accountability Act（已生效）；犹他 2027.5；路易斯安那/加州等跟进 | 2026 起陆续 | 接入 Apple Declared Age Range API，按信号分级处理 |
| 违规成本 | SB 243：私人诉权，每次违规 ≥$1,000；纽约：最高 $15,000/天 | — | 上线前逐项自查为法务底线，不是"最佳实践" |

**欧盟/英国**：GDPR 基线（合法性基础、数据最小化、删除权——已由删号+记忆册删除覆盖）；意大利对 Replika 的禁令与 €500 万罚款说明欧盟监管对"情感 AI+未成年人"高度敏感。上线欧区前把隐私政策做扎实即可，暂不需要 DPO 级投入。

## 2. 中国开发者身份的注意事项

**本作策略 = 海外发行（App Store 排除中国大陆 + Steam 全球服），从而不触发国内牌照义务**。但仍有三件事要清楚：

1. **版号灰色地带**：全球 Steam 发行本身不需要版号（版号只在国内运营/蒸汽平台需要）。但"国产游戏未取得版号在境外平台向国内玩家提供服务"在国内法律界存在灰色地带讨论——本作不做国内推广、不设国内支付，风险敞口小，**收入成规模后咨询一次游戏行业律师**。
2. **外汇与税务**：Steam/苹果结算的境外收入，走个人年度 $5 万便利化结汇额度；依法申报个人所得税（保留结算单据）。年收入到几十万人民币量级时，评估注册个体户/公司主体（也为日后转苹果组织账号、接发行商做准备）。
3. **生成式 AI 备案**：只约束"向中华人民共和国境内公众提供服务"——本作海外发行不触发；**不要**为国内用户单独开服务入口，否则整套义务（算法备案、大模型备案，均需公司主体）立即落到头上。

## 4. 伦理风险：情感依赖（本作最特殊的一条）

**背景**：Character.AI 因未成年人自杀诉讼于 2026.1 进入和解；诉状核心指控是"刻意设计依赖与拟人化欺骗"。中国 2025.12 也点名整治"情感操纵型"聊天机器人。**这既是道德问题，也是产品的生存问题。**

**本作的六条设计承诺**（已落进 docs/01 §1 红线与 §6）：
1. **透明**：永不伪装人类；AI 身份披露常驻
2. **不惩罚离开**：无签到断签惩罚、无负罪感推送、好感不因离线衰减
3. **不情感勒索**：角色永不说"你不来我会难过/受伤"类话术（写进人设卡负面约束与输出扫描规则）
4. **鼓励现实**：角色价值观内置"希望你在现实里也好起来"；深夜陪伴但劝休息
5. **记忆主权**：用户可查看/修正/删除她记得的一切
6. **危机不留人**：危机信号一律转介专业资源，绝不尝试"自己接住"

这六条同时是**营销叙事的差异化资产**（"一个希望你越来越不需要她的 AI 伴侣"）——把伦理成本转化为品牌价值。

## 5. 隐私政策要点清单（写给律师/自己起草用）

- 数据地图：收集什么（账号、对话内容、语音片段、设备信息）/ 存哪（Supabase 区域）/ 留多久 / 谁能访问
- **第三方共享点名**：LLM 供应商（Anthropic/OpenAI/…）、TTS/STT 供应商——苹果 5.1.2(i) 要求点名 + 明确同意
- 用户权利：导出、修正、删除（应用内一键删号）；未成年人政策（16+，不面向未成年人）
- 语音数据：默认不留存原始音频（转文字即弃）——既省合规也省存储
- 对话内容用途限定：仅用于生成回复与记忆功能，**不用于训练模型**（与供应商签 no-training 条款/选用不训练的 API 档位）——这句话对本品类用户的信任价值极高
- 危机日志的特殊处理：留存目的、期限、访问权限单独说明
