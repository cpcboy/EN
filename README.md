## 30 秒速览

**核心结论**：赛道需求真实（AI 陪伴 App 2025 年内购约 $1.2 亿，同比 +64%），但尚无 LLM 买断制游戏跑出百万美元级成功。赢法是**"窄而深 + App 化变现 + 成本工程"**，不是"宽而炫的开放世界"。

**v1 形态**（数据依据见 docs/00）：
- **1 位深度角色**（咖啡馆老板娘"小满"）+ **1 个可漫游的温暖小场景**（灯塔咖啡馆与堤岸，A Short Hike 式尺度）
- 真记忆（她记得你说过的一切，且记忆册可查看、可删除）+ 健康向好感度（好感靠对话质量，不靠刷礼物）
- "逛小镇结交多位伴侣"的完整愿景保留为二期蓝图，v1 验证成功后展开

**关键数字**：

| 项 | 数字 |
|---|---|
| 启动现金（首年） | 约 $400–900（Steam $100 + Apple $99/年 + 资产与工具可选项） |
| 时间线（兼职） | 约 8 个月到 Steam Early Access，约 12 个月完成 iOS 上架 |
| 运行成本 | 重度用户约 $2–3.5/月（LLM+语音），靠每日额度与订阅覆盖 |
| Steam 新游戏中位收入 | 约 $249（2025 年，认真做的独游中位 $5K–15K） |
| 愿望单基准线 | 7,000 触发 Popular Upcoming；转化中位约 15% |

**三大风险**（详见 docs/06）：
1. **推理成本**：每玩家 API 成本是 LLM 游戏反复致死的结构性问题 → 立项第 0 号验证 + 额度/订阅设计
2. **平台与监管**：苹果对 AI 陪伴类收紧、Steam AI 污名与支付渠道压力、美国州法新义务 → 16+ 健康定位 + 合规内建
3. **情感依赖伦理**：Character.AI 诉讼先例 → "鼓励现实生活"写进角色价值观，透明、不惩罚离开、好感不出售

**立即可做的三件事**：
1. 注册 Steam 开发者账号并付 $100（30 天等待期从付费日起算，越早越好）→ docs/04
2. 跑通 M0 成本验证原型（LLM+TTS 管线 + 1000 轮对话压测）→ docs/03
3. 注册游戏社媒账号，开始记录开发过程（愿望单的种子）
